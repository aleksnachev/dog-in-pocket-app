# AI сървър (по избор)

Приложението работи напълно и без него – локалното търсене покрива проверената база. AI сървърът добавя бутон „Обясни ми по-подробно (AI)“ под резултатите.

## Как пази отговорите проверени
- Получава само въпроса, обобщен профил (без името на кучето) и откъсите от базата, които приложението вече е намерило.
- Системната инструкция забранява факти извън тези откъси, диагнози, лекарства и дози.
- Отговорът е структуриран JSON (`answer`, `citations`, `urgent`). Сървърът маха цитати, които не са сред подадените откъси, и връща реалните източници.
- При отказ от модела връща безопасен текст с препоръка за ветеринар.

## Настройка (Cloudflare Workers)
```bash
cd server
npm install
npx wrangler login
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put ACCESS_CODES
npx wrangler deploy
```
`ACCESS_CODES` е списък с кодове, разделени със запетая (напр. по един на купувач). Адресът, който `deploy` отпечата, се слага в `js/config.js` → `aiEndpoint`. Кодът купувачът въвежда в „Моето куче → Настройки“.

По избор: KV namespace `USAGE` (вижте `wrangler.toml`) за дневен лимит въпроси на код (`DAILY_LIMIT`, по подразбиране 30).

## Модел и цена
По подразбиране `claude-opus-5-5` с `effort: "low"`. За по-ниска цена на въпрос може да се зададе `MODEL = "claude-haiku-5-5"` в `wrangler.toml`. Това е бизнес решение – тествайте качеството на отговорите на български, преди да смените модела. Системната инструкция се кешира (`cache_control`). Включено е автоматично пренасочване към друг модел, ако моделът откаже (`fallbacks: "default"`).
